# Taxi1729 Poll

Sondaggi live per gli eventi Taxi1729, integrati in PowerPoint (Windows e Mac).

## Contenuto del repository
- `app/` — l'applicazione (Cloudflare): server, pannello web, pagina del pubblico,
  presentazione da browser e add-in PowerPoint. Vedi `app/README.md`.
- `loadtest/` — test di carico (1000 telefoni simulati), avviabile da GitHub → Actions → "Test di carico".
- `.github/workflows/` — configurazione del test di carico su GitHub Actions.

Il primo prototipo (GitHub Pages + messaggistica pubblica) è stato rimosso; resta consultabile nella storia del repository.
